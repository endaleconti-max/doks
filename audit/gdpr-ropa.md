# Record of Processing Activities (RoPA)

Date: 2026-03-25
Controller: User-operated local deployment
Product: DocumentOrganizer

## Activity 1: Document Organization
- Purpose: Classify and organize user files.
- Categories of data subjects: End users and document owners.
- Categories of personal data: Names, addresses, contact details, identifiers, and any personal content present in uploaded files.
- Legal basis: Legitimate interest / performance of user-requested processing in local environment.
- Recipients: None by default (local-only).
- Transfers: None.
- Retention: Privacy preset dependent retention policy.
- Security measures: Local-only processing, permission-gated tools, audit trail, planned encryption-at-rest baseline.

## Activity 2: Audit and Rights Support
- Purpose: Provide action traceability and data-subject handling support.
- Categories of data: Event metadata and optional identifiers.
- Legal basis: Compliance and accountability obligations.
- Recipients: User exporting audit logs.
- Transfers: None.
- Retention: Policy-defined lifecycle, deletable by user.
- Security measures: Local state control, no remote telemetry.

## Activity 3: Plugin Permission Governance
- Purpose: Enforce least-privilege execution for tool extensions.
- Categories of data: Plugin identifiers, permission grants, execution events.
- Legal basis: Security and accountability controls.
- Recipients: None by default.
- Transfers: None.
- Retention: Local state lifecycle.
- Security measures: Explicit grant/revoke, audit logging for permission changes.
