# GDPR Legal Basis Mapping

Date: 2026-03-25
Product: DocumentOrganizer

## Processing to Basis Matrix

1. Import and categorize user documents
- Basis: User-requested processing (service functionality)
- Notes: Local execution only; no third-party sharing by default.

2. Persist organizer state and metadata index
- Basis: Legitimate interest in maintaining requested app functionality and data integrity
- Notes: Retention policy configurable by privacy presets.

3. Store audit events and export audit timeline
- Basis: Accountability and user transparency
- Notes: Supports compliance evidence and user review.

4. Manual recategorization and correction-learning persistence
- Basis: User action and legitimate interest in improving classification outcomes
- Notes: User can delete records and corrections through lifecycle controls.

5. Plugin permission records and tool execution events
- Basis: Security and accountability controls
- Notes: Least-privilege model with explicit grants and audit logs.
